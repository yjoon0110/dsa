# DSA Study Hub

Three files run this system:

| File | Purpose |
|------|---------|
| [`plan.md`](plan.md) | Problem-solving template, pattern cheat sheet, daily ritual |
| [`problems.md`](problems.md) | Week-by-week LeetCode problem list with links |
| [`progress.md`](progress.md) | Your personal log — problems solved, insights, revisit queue |

**Start here:** Read `plan.md` once, then open `problems.md` and begin Week 1.

## How to Use

1. **Work in order** — each module builds on the previous one.
2. **Type the code yourself** — don't just read; run and modify.
3. **Do exercises before peeking** at solutions.
4. **Log every problem** in `progress.md` — one sentence on what you learned.
5. **Consistency > cramming** — 45 min daily beats 5 hours once a week.
